# 《明日方舟》与《明日方舟：终末地》平面设计语言分析

> 研究日期：2026-10-11。结论基于官方公开官网及公开宣传/界面资料，是观察和归纳，不是官方视觉识别规范。网页中的图形是原创示意，色值为近似教学样本。

## 1. 相同的视觉基因

这两个系列都把设计视为游戏世界内部的**信息与组织系统**：编号、部门、文件、符号、低色彩饱和度、硬边界、纵横辅助线，以及刻意设计的视觉层级。这使视觉不仅指向科幻/工业题材，还向玩家传达“一个运作中的机构真实存在”的感觉。

共性原则：

1. **网格作为秩序**：不把辅助线只用于装饰，而让它们暗示规划、定位、工业文档。
2. **字体作为图形**：大字号压缩标题 + 编号/坐标/辅助文本的尺度差，制造冲击与冷静的对比。
3. **识别符号体系**：警告条、斜切角、技术十字、强对比块，构成机构/设备语义。
4. **灰度占主导**：在低色彩复杂度上体现优先级，少量重点色集中于状态与焦点。
5. **叙事性与可用性并存**：即使是海报或主视觉，也常像世界内部档案或工程报告。

## 2. 原作《明日方舟》：战术档案 × 工业末世

- **形式**：深煤黑和冷灰为基础，蓝青色界面亮点；战术、医疗、机构档案语言；斜向分区、错位叠加、章节序号、参数条。
- **视觉材料**：摄影质感插画、雾、颗粒、局部纹理、残缺/刮擦、低饱和影调；人物/场景叙事主导。
- **文字排版**：多级大写英文、强对比标题、等宽编号；中英文双语配合制造文件感。不同活动采用不同字体/色系，不存在所有活动完全相同的单一平面风格。
- **适配场景**：情报档案、角色档案、视觉叙事海报、章节封面、世界观资料浏览。
- **常见误区**：不是“黑底上随便放几个青蓝色按钮”；也不是所有内容都要故障、斜切或高密度小字。

**教学色彩近似值**：#1A1C20（煤黑）、#55BCD0（青）、#3F72AF（蓝）、#DCE1E3（档案纸灰）、#D88D4A（警告橙）。

## 3. 《明日方舟：终末地》：工业编辑设计 × 工程制图

- **形式**：纸白/灰和墨黑的强烈对撞，以标志性荧光黄构建主要焦点。黑底终端与纸色界面可交替存在。
- **排版**：超大宽体或压缩英文、数字视觉符号、工程资料信息层次、局部文字竖排、印刷边角校准标记。
- **图形**：网格、坐标、框线、点阵扫描、雷达圈、设备状态、流程和信息可视化，常见直角及切面几何。
- **动态图形**：短促扫描、状态点亮、数据进入、转场；可使用点云/3D/粒子，但应该被内容层级控制。
- **适配场景**：设计系统、运营控制台、产品后台、信息可视化、科技活动海报。
- **常见误区**：不是所有区域都铺满荧光黄，也不是只依靠黑黄配色；需要通过字重、信息结构与几何合理性建立风格。

**教学色彩近似值**：#F4ED17（亮黄）、#151719（墨黑）、#E8E8E2（纸白）、#707577（钢灰）、#2D3337（深面板）、#EF4779（低频套印点缀）。独立设计拆解记录的官网签名黄为 `#fffa00`，可作为其在线网站的色值研究资料，但不能据此断言游戏所有版本或物料都采用同一数值。

## 4. 系统对比

| 维度 | 明日方舟 | 终末地 |
|---|---|---|
| 叙事主题 | 战术 / 组织 / 感染者 / 末世 | 制造 / 探索 / 工程 / 数字系统 |
| 重心 | 情绪、故事、机构档案 | 功能、规模、流程、可视化 |
| 基调 | 深、冷、含蓄、复杂质感 | 极高对比、清晰、理性、直接 |
| 重点色 | 青蓝等依场景变化 | 高辨识度警示黄 |
| 字体层级 | 故事标题 + 档案小字 | 超大系统标题 + 技术编号 |
| 构图 | 层叠、非对称、拼贴 | 规则网格、留白、极端尺度对比 |
| 动效 | 错位揭示、故障、淡入 | 扫描、脉冲、精确运动、数据变化 |

## 5. 面向产品的工程化设计约束

- 灰阶承载 80% 以上日常信息，颜色只给主要操作、警报/状态/重要分类。
- 文字层级建议：12–13 px 操作正文、10–11 px 技术标记、24–48 px 组件标题、56–110 px 展示大字。以上为演示建议，不是游戏实测规范。
- 保持直角、1px 分隔线和清晰间距；避免为装饰而增加噪声、复杂边框。
- 使用自适应设计，而不是只基于一个 2560px 宽度等比缩放小字；手机端优先可阅读性。
- 动效作用必须可说清楚：扫描表示检测，脉冲表示数据流，状态灯表示连接，内容揭示表示层级。
- 必须有 `prefers-reduced-motion` 兜底；功能性反馈无需复杂动画。
- 安全区分：游戏原版设计、第三方拆解与本项目二次归纳；不把近似色值称为“官方规范”。

## 7. 本网页中如何验证这些规则

- 两个风格模式用于直接对照视觉层级和色卡。
- 海报实验室在相同结构下切换模板、字体、密度与强调色，验证视觉语言并不是一张背景图。
- 控制台演示将视觉语义延伸到交互按钮、运行状态、进度条与数据视图。
- 动态语言板提供扫描、信号脉冲与裁切揭示，且均可一键禁用。
